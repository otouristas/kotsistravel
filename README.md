# Kotsis Travel

Modern rebuild of [kotsistravel.gr](https://www.kotsistravel.gr/) — travel agency based in Igoumenitsa, Greece (est. 1975).

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Fully responsive

## Features

- Modern responsive design
- Greek primary language
- Pages: Home, Για Εμάς, Ακτοπλοϊκά, Αεροπορικά, Ξενοδοχεία, Εκδρομές, Κρουαζιέρες, Μεταφορές, Επικοινωνία
- SEO metadata
- Original logo + ESPA banner

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
